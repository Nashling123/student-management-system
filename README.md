🎓 Student Management System

A modern, responsive web application designed to simplify student registration and academic record management.

🚀 Overview

Student Management System is a user-friendly web application that provides a centralized interface for managing student information.

The application follows a simple and structured workflow:

Register → Login → Manage Students → View Records

Users can create an account, securely access the dashboard, register student details, view records in a professional table, and remove records when required.
